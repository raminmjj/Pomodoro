# Implementation Plan: Remaining Features for Pomodoro App v3

## Gap Analysis Summary

After auditing every source file against `Pomodoro_AOT_Architectural_Plan_v2.md`, the codebase is ~90% complete. The following 10 gaps remain:

---

## Phase 1: Critical AOT Compatibility Fixes

### 1.1 Enable Compiled Bindings
- **File**: `Directory.Build.props`
- **Change**: Set `<AvaloniaUseCompiledBindingsByDefault>true</AvaloniaUseCompiledBindingsByDefault>`
- **Risk**: May cause build errors if any AXAML bindings are not compile-time resolvable. Fix any resulting errors by adding `x:DataType` directives to views.

### 1.2 System.Text.Json AOT-Safe Serialization
- **Files**: `DailyReportViewModel.cs`, `ReportingService.cs`
- **Problem**: `JsonSerializer.Serialize`/`Deserialize` uses reflection-based overloads that get trimmed.
- **Fix**: Create a `JsonSerializerContext` with `[JsonSerializable]` attributes for `TaskBreakdownItem`, `int[]`, and the anonymous breakdown DTO. Use source-generated context in all serialize/deserialize calls.
- **New file**: `src/Pomodoro.Application/DTOs/ReportJsonContext.cs`

### 1.3 Create Missing appsettings.json
- **File**: `src/Pomodoro.App/appsettings.json`
- **Content**: Default Serilog configuration and any runtime settings referenced by `Microsoft.Extensions.Configuration.Json`.

## Phase 3: Platform Robustness

### 3.1 macOS Accessibility Permission UX
- **File**: New `src/Pomodoro.Infrastructure/Hooks/MacOsAccessibilityChecker.cs`
- **Logic**: On macOS, before starting SharpHook, check accessibility permission via CGPreflightListenEventAccess(). If denied, show a dialog directing user to System Preferences > Security & Privacy > Accessibility with a button that opens the pane via `open "x-apple.systempreferences:..."`.
- **Integration**: Call from `SharpHookActivityTracker.StartTrackingAsync()` or from `App.OnFrameworkInitializationCompleted()`.

### 3.2 Wayland Fallback Warning
- **File**: `SharpHookActivityTracker.cs`
- **Logic**: Wrap `_hook.RunAsync()` in a try/catch. If it fails on Linux and Wayland is detected (env var `WAYLAND_DISPLAY` is set), log a warning and expose a user-visible message via `INotificationService` suggesting XWayland fallback.

### 3.3 Persist Cycle Counter Across Restarts
- **File**: `PomodoroEngine.cs`
- **Change**: On startup, query the most recent `PomodoroSession` from the repo to restore `_cycleIndex`. On each cycle increment, the value is already persisted via the session's `CycleIndex` field — just need to read it back on init.
- **Method**: Add `InitializeAsync(CancellationToken)` called from `Program.StartEngineTickLoop` before starting the tick loop.

2. Phase 2 (UI features) — independent of each other, can be parallelized
3. Phase 3 (Platform robustness) — independent of Phase 2
4. Phase 4 (Testing) — after all features are implemented
