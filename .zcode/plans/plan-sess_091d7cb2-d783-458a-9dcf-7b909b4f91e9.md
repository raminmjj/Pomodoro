# Plan: Adopt sourcegit-master Workflow Structure for Pomodoro

## Overview
Replace the monolithic `ci.yml` with sourcegit-master's modular workflow architecture, adapted for the Pomodoro project. Full adoption including platform-specific packaging (macOS .app, Linux .deb/.rpm/.AppImage). Version derived from git tags.

## Key Adaptations
- **Project path**: `src/Pomodoro.App/Pomodoro.App.csproj` (not `src/SourceGit.csproj`)
- **Assembly name**: `Pomodoro` (not `SourceGit`)
- **App ID**: `com.pomodoro.Pomodoro` (reverse domain)
- **Icon**: Reuse existing `src/Pomodoro.App/app.ico` and `src/Pomodoro.App/Assets/appicon.png`
- **No VERSION file** — version extracted from git tag (`v1.0.7.0` → `1.0.7.0`)
- **Branches**: `master` (not `develop`)
- **Skip**: homebrew-notify.yml, localization-check.yml (not applicable)
- **Add**: format-check.yml adapted for Pomodoro solution
- **Test job**: Keep existing test + codecov step in ci.yml

## Files to Create

### 1. `.github/workflows/build.yml` (reusable)
- Adapted from sourcegit's build.yml
- Matrix: win-x64, win-arm64, osx-x64, osx-arm64, linux-x64, linux-arm64
- Uses `actions/checkout@v6`, `actions/setup-dotnet@v5`, `actions/upload-artifact@v7`
- Publishes `src/Pomodoro.App/Pomodoro.App.csproj` with `-p:PublishAot=true`
- Linux container: `ubuntu:20.04` with GLIBC 2.31 compat
- Renames executable to `pomodoro` on Linux
- Uploads artifacts as `pomodoro.<runtime>`

### 2. `.github/workflows/ci.yml` (entry point)
- Triggers: push to master, PRs to master, workflow_dispatch
- Jobs: test (build + test + codecov), build (calls build.yml), package (calls package.yml with tag-derived version)
- Test job runs `dotnet test` with coverage on ubuntu-latest

### 3. `.github/workflows/release.yml` (tag-triggered)
- Triggers: `v*` tags
- Jobs: build → version (from tag) → package → release (gh release create + upload)
- Uses `actions/download-artifact@v8`

### 4. `.github/workflows/package.yml` (reusable)
- Input: `version` string
- Windows: zip packaging via PowerShell script
- macOS: .app bundle creation via shell script
- Linux: .deb, .rpm, .AppImage via shell script
- Uses `geekyeggo/delete-artifact@v6` to clean temp artifacts

### 5. `.github/workflows/format-check.yml`
- Triggers: push/PR to master, workflow_dispatch
- Runs `dotnet format --verify-no-changes` on the solution

### 6. Delete old `.github/workflows/ci.yml` (replaced by new modular set)

## Packaging Scripts to Create

### 7. `build/scripts/package.win.ps1`
- Remove PDBs, Compress-Archive to `pomodoro_$VERSION.$RUNTIME.zip`

### 8. `build/scripts/package.osx-app.sh`
- Create `Pomodoro.app/Contents/MacOS` structure
- Copy binary, icon (.icns generated from appicon.png or placeholder), Info.plist
- Zip to `pomodoro_$VERSION.$RUNTIME.zip`

### 9. `build/scripts/package.linux.sh`
- AppImage: Create AppDir, copy binary + .desktop + icon + appdata.xml, run appimagetool
- DEB: Build with dpkg-deb using control template with ICU deps
- RPM: Build with rpmbuild using spec template

## Resource Files to Create

### 10. `build/resources/app/App.plist`
- macOS Info.plist template with `POMODORO_VERSION` placeholder
- Bundle identifier: `com.pomodoro.Pomodoro`

### 11. `build/resources/_common/applications/pomodoro.desktop`
- freedesktop .desktop file for Pomodoro timer

### 12. `build/resources/_common/icons/pomodoro.png`
- Copy from `src/Pomodoro.App/Assets/appicon.png`

### 13. `build/resources/appimage/pomodoro.appdata.xml`
- AppStream metadata for Pomodoro

### 14. `build/resources/deb/DEBIAN/control`
- Debian control file template with placeholders for version, arch, ICU deps

### 15. `build/resources/rpm/SPECS/build.spec`
- RPM spec file template for Pomodoro

### 16. macOS icon
- Generate `build/resources/app/App.icns` from existing `appicon.png` (or create placeholder)

3. Create workflow files: build.yml, package.yml, ci.yml, release.yml, format-check.yml
